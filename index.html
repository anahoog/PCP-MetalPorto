Conexão com a planilha

A publicação CSV do Google Sheets permite consultar os dados publicados. Para gravar alterações na planilha original e compartilhar mudanças entre usuários, é necessário configurar um Google Apps Script autorizado.

A planilha publicada que você compartilhou não revela, por si só, o endereço editável nem os nomes das colunas. Por isso, esta versão não grava automaticamente nela ainda; isso evita alterar a coluna errada ou sobrescrever dados.
O botão abaixo tenta carregar os dados publicados. Se o navegador bloquear a consulta, use o botão para importar um CSV baixado do Google Sheets.
Preencha somente depois de implantar e testar o script de integração. O HTML não envia alterações a um endereço não configurado.
Dados locais ainda não foram sincronizados com uma planilha nesta sessão.

Como os dados estão sendo tratados

  • As alterações de estoque ficam neste navegador até existir uma integração de gravação autorizada.
  • Importar um CSV substitui a lista local atual; exporte um backup antes, se precisar preservar os registros locais.
  • Não publique informações confidenciais da empresa em uma planilha ou site acessível publicamente.
